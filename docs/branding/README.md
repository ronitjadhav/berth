# Berth artwork

![Berth](wordmark.svg)

The logo brings three container blocks together in one compact stack.
Use the orange mark for repository artwork and social profiles.
The extension uses a monochrome version so GNOME can apply theme and status colours.

| Use | Asset |
| :-- | :-- |
| Scalable logo | [Orange](mark.svg), [charcoal](mark-mono.svg), [white](mark-white.svg) |
| Name and logo | [Charcoal text](wordmark.svg), [white text](wordmark-white.svg) |
| Social avatar, 1024 × 1024 | [Light](avatar.png), [dark](avatar-dark.png), [orange](avatar-orange.png) |
| Repository social card, 1280 × 640 | [PNG](social-card.png) |
| GNOME panel | [Symbolic SVG](../../icons/berth-symbolic.svg) |

Orange is `#F46B35`, charcoal is `#27272B`, and the light background is `#FAF7F2`.
Keep each mark square. Leave clear space of at least one eighth of its width.
The avatars include room for a circular crop.
Use the symbolic icon at panel sizes; its wider gaps keep the containers separate.

The wordmark contains vector outlines, so it needs no installed font.
Its lettering uses DejaVu Sans Bold. See the [font license](FONT-LICENSE.txt).
The original logo artwork uses the repository's [license](../../LICENSE).
